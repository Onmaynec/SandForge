# 🖥️ Интерактивный TUI

SandForge `0.4.0-alpha` запускает keyboard-first интерфейс на Spectre.Console, если команда вызвана без аргументов:

```powershell
sandforge
```

Все прежние CLI-команды остаются доступны для PowerShell, CI и автоматизации.

## Dashboard

Главный экран показывает:

- доступность Windows Sandbox;
- путь SQLite и каталога данных;
- выбранный язык;
- пять последних сессий со статусом и риском.

## Мастер запуска

Мастер запуска:

1. проверяет существование целевого файла;
2. предлагает доступные built-in и пользовательские шаблоны;
3. строит план сессии и вычисляет SHA-256;
4. показывает network, clipboard, timeout, mounts, collectors и security findings;
5. требует отдельного подтверждения, если план включает высокий риск, сеть, clipboard или writable mount;
6. показывает live-статусы host lifecycle;
7. после завершения позволяет создать HTML или JSON report.

Заблокированный Security Policy план нельзя подтвердить через TUI.

## Сессии и обслуживание

Из TUI доступны:

- просмотр console report и списка артефактов;
- генерация HTML/JSON отчётов;
- удаление сессии с повторной проверкой workspace path;
- crash recovery;
- cleanup с обязательным dry-run preview;
- просмотр и очистка managed cache;
- проверка и применение обновлений.

## Совместимость терминала

Spectre.Console автоматически снижает использование ANSI-возможностей в ограниченных терминалах. При перенаправленном stdin/stdout SandForge не открывает интерактивный интерфейс и печатает CLI help.

Все сценарии доступны с клавиатуры: стрелки, Enter, Escape/Ctrl+C и текстовые поля.
